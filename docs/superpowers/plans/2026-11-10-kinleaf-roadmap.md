# 枝间 Kinleaf 后续开发路线

以 v0.1.0「纸本谱册」为基线，参考用户提供的丝连族谱主界面截图与吊线图导出。继续采用 Windows x64 单文件 EXE、离线运行和本机 SQLite。下列版本号及优先级为提案，各阶段在确认范围后拆为可独立验证的实施任务。

## v0.2 · 修谱与数据保护

1. **备份与恢复。** 将入口放在「系统工具」。备份使用 SQLite 一致性快照，恢复前校验格式、版本、完整性、外键、始祖和世系可达性。恢复创建独立副本。验收覆盖备份后编辑原谱、恢复旧状态、损坏文件拒绝和同机多谱隔离。
2. **家谱信息与快速登记。** 在顶部补充谱名维护，在族员标题处提供添加配偶、儿子和女儿。复用现有登记和亲属关系入口，补齐可空的性别字段。亲属档案可独立编辑。沿用现有删除登记规则，有后代时要求先处理下级。验收包含 v0.1 数据升级，未知性别仍显示未知。
3. **调整排行和母子关联。** 在同一上级的子女列表内支持上移、下移或输入排行，事务保存整组顺序。在选中子女的详情中明确关联生母，允许未知或改正已有记录。谱系上级仍代表登记归属。验收包含刷新后顺序稳定、保存失败回滚、变更生母后世系路径保持原样。

## v0.3 · 查谱与日常使用

1. **世系导航。** 增加展开和收起当前分支、重新加载。字体与行距可调并保存在本机。
2. **溯源与收藏。** 查看始祖到当前登记的路径，可点击祖先返回。兼祧从当前登记计算路径。收藏可直接回到对应登记，删除后自动从收藏清单移除。
3. **统计与校验。** 展示族员登记数、去重个人档案数、配偶关系数和各世人数，分开标明统计口径。提供重名、重复排行和缺失关系的检查结果。用合成的同名、兼祧和配偶样本核对数量，保留未录入项的提示。
4. **修谱日记。** 先做可关联族员的本地手工记录，明确记录日期与内容。作为独立子任务，可移到统计之后交付。

## v0.4 · 出谱与资料交换

1. **生成图表。** 从整谱或选定分支生成吊线图预览，先支持 SVG 和打印为 PDF。预览提供纸张方向和世代范围。验证长姓名、同名、多配偶、8 世以上和跨页断线标记。谱文、欧式文表、横竖排印刷模板按需求追加。
2. **导入向导。** 支持明确格式的旧版数据表格和本次已验证的吊线图工作簿。预览列出可导入数量、缺失字段与异常，再创建独立族谱。按源登记标识或图形连接处理，保留同名记录。验证重复导入提示、缺上级、异常连线和半途失败。Access 原库读取单独评估。
3. **照片。** 在档案中添加本地照片，明确其归属与备份范围。截图显示旧版有照片区域，当前导出的吊线图工作簿没有可供映射的照片资料。

## 发布顺序与完成标准

- 推荐顺序为先备份恢复，再修谱操作，然后查谱与出谱。备份可先独立交付。
- 每个版本先验证 v0.1 已有族谱可打开，以及原有建谱、编辑、搜索定位与兼祧流程。正式发布沿用 Windows 单文件 EXE。
- 导入和导出使用合成测试谱验证。真实族谱和照片保留在用户本机。
- 截图中的「更新」先通过现有 GitHub Releases 提供下载。应用内自动更新单独评估。
- 旧计划中的 NSIS 交付以当前单文件要求为准。照片、日记和出谱属于拟新增范围。
