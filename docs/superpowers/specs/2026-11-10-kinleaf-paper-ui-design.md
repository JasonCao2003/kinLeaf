# 枝间 Kinleaf 纸本谱册界面设计

## 目标

让族谱打开后就能浏览世系，选中一人即可查看档案并进行修谱操作。在 Windows 单机版里延续纸本家谱的阅读感。

## 方案

- 选定纸本谱册。以暖纸色为底、松墨绿为主色，朱褐标记当前登记与世代。谱名和族员姓名用系统宋体，表单和按钮用系统无衬线字体。
- 对照方案为现代档案馆，使用蓝灰配色与较紧凑的列表。用户在交互草图中选定纸本谱册方向。

## 工作区

- 顶部展示「枝间 Kinleaf」与当前谱名，提供切换族谱和新建族谱入口。
- 左侧放姓名或谱名搜索和可展开的世系树。点击搜索结果后展开祖先路径，高亮对应登记。
- 右侧先显示族员姓名、世代、祖先路径和「登记后代」。下方分为「个人档案」「支系登记」「亲属关系」，各自保存。切换分区保留同一族员的未保存输入。
- 宽窗口使用左右分栏，窄窗口上下排列。键盘可进入搜索、世系和表单，焦点及选中状态清晰可见。
- 未选谱时显示打开与建谱入口。空搜索结果、加载失败和保存错误都有文字反馈。

## 范围和验收

复用现有 Tauri 命令和数据模型，支持已导入族谱及现有建谱、搜索、兼祧和亲属维护流程。系统字体和本地样式支持断网使用。使用现有前端测试验证搜索定位和切谱，并补测切换档案分区时的草稿保留。通过后编译 Windows x64 单文件 EXE。
