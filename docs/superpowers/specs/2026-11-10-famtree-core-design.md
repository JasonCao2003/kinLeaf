# 枝间 Kinleaf 单机版核心功能设计

## 目标与范围

在 Windows 上离线新建、维护和查阅家庭族谱，并能备份后在另一台安装了 枝间 Kinleaf 的电脑上恢复。功能参考丝连族谱帮助文档中的建谱、族员编辑、个人档案和世系树。首版交付可安装的桌面应用。

首版包含新建与切换族谱、族员与亲属关系编辑、兼祧登记、世系浏览、族员搜索、本地备份与恢复。Access 迁移、分支合并、谱文排版、PDF 和其他出谱功能留在首版范围之外。

## 方案选择

- 已选 Tauri + Rust + Vue + SQLite。桌面窗口承载 Vue 界面，Rust 通过 Tauri 命令提供数据操作和备份，SQLite 保存族谱。
- 备选为 Rust 本地服务 + Vue + SQLite，浏览器访问本机服务。调试方便，日常使用要管理本地服务的启动和退出。

## 数据与关系

- 每份族谱使用独立 SQLite 文件，存放在应用数据目录。族谱有独立标识、名称和一个始祖登记。启动后可新建、打开或恢复族谱。
- 个人档案保存姓名、谱名、字辈、生卒文字和备注。日期可未知，也可保留原始记法。同名人员可独立登记。首版以文字档案为主。
- 族员登记引用个人档案，可额外保存支系备注和排行。同一档案可关联多条族员登记。编辑共有档案时，界面提示会影响该人的其他登记。
- 每条后代登记指定一个谱系上级，形成以始祖为根的树。另可登记已知生父、生母及配偶关系，关系引用个人档案，可保留未知项，可登记多位配偶。谱系上级表达修谱归属，亲属关系表达个人之间的关系。
- 事务内校验引用和谱系循环。禁止将族员登记挂在本人的登记下，禁止构成生父母关系循环。始祖保留为根节点。有下级的登记须先迁走下级，再删除。删除登记保留个人档案及其亲属关系。

## 日常操作

1. 输入谱名和始祖姓名即可创建族谱。
2. 从任一登记新增后代，可新建个人档案，也可选用现有档案登记兼祧。详情可维护亲属关系和编辑现有登记。
3. 世系视图按谱系上级逐层展开，选中登记后查看个人资料、配偶、已知父母及其他登记位置。世代按谱系层级计算，始祖为第一世。兄弟姐妹按排行排序，同排行用稳定顺序显示。
4. 按姓名或谱名搜索。命中多条登记时列出世代和祖先路径，选择结果可定位到对应位置。

## 备份与恢复

通过 SQLite 一致性快照导出独立备份文件。恢复前校验文件格式、架构版本、数据库完整性和引用关系。恢复为一份独立族谱，生成新的族谱标识。取消或恢复失败时保留已有族谱；文件校验完成后才将新族谱加入打开列表。

## 验收

- 断网状态下安装后可建谱、编辑、搜索，重启后可重新打开。
- 为同一人建立两个支系登记，搜索可分别定位。修改该人的档案，两处均显示更新，各自保留支系备注和排行。
- 尝试把上级移到其后代之下，操作被拒绝，原世系可继续浏览。
- 同名人员可独立查询。配偶和生父母资料缺失时，仍可查阅和维护世系。
- 备份可恢复为可编辑的独立副本。损坏文件无法恢复，已有族谱可继续打开。

## 设计提议与实现边界

Windows 首发、每谱独立文件、单始祖树、首版文字档案及恢复为独立副本为本稿提出的默认选择。组件划分、版本锁定、安装包格式、命令签名与验证命令由实施计划确定。
